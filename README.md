
# Raytracer Engine

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)

![GitHub commit activity](https://img.shields.io/github/commit-activity/t/Yousef-Albasel/Raytracer)

This project is a deep dive into the fundamentals of ray tracing, bringing the math of light, shadows, and reflections to life through code. Built from scratch with C++ and OpenGL, it demonstrates how virtual worlds can be rendered with physically inspired accuracy.

## Key Features:

Ray-Sphere & Ray-Plane Intersections – foundational geometry for rendering objects.

Shadows & Reflections – realistic lighting behavior using recursive ray tracing.

Material System – diffuse, reflective, and refractive surfaces for diverse scenes.

Camera Controls – interactive navigation with adjustable field of view.

Multi-threading Execution - Pretty fast image rendering

Future Work

Acceleration structures (BVH, KD-trees) for faster rendering

More advanced materials (glass, glossy reflections, textures)

## Installation

```bash
  git clone https://github.com/Yousef-Albasel/Raytracer
  cd Raytracer
```
Make sure you’re using Visual Studio 2019/2022 with Desktop development with C++ workload installed.

In Visual Studio, set the solution platform to x86 (32-bit).
